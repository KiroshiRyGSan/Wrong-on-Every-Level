🚫 Wrong on Every Level Wrong on Every Level is a politically incorrect 2D action-platformer built with Python and Pygame. It’s a satirical journey through social stereotypes, global politics, and dark humor, where "fairness" is just a myth and your social status defines your difficulty level.

🎭 Choose Your Privilege (Difficulty Settings) The game features a unique character-selection system where difficulty is tied to the protagonist's social background:

The Priest (EASY) - [STATUS: COMPLETED]: Armed with divine projectiles and high defense. His power-up triggers the "Ascension" transformation, turning him into a vengeful Angel.

Cis-Privileged Male (MEDIUM) - [STATUS: TODO]: The average joe. His power-up transforms him into the "Combat Patriot", a tactical fighter ready to defend his status quo.

Black guy (HARD) - [STATUS: TODO]: The ultimate survival challenge. His unique mechanic is the "Victim Card", a strategic ability to flip power dynamics and confuse systemic enemies.

⚔️ Satirical Enemies & World Leaders Battle against the most controversial figures on the global stage. Boss fights include caricatures of international leaders (like Trump or Maduro) and enemies based on the most cringeworthy social stereotypes.

🚀 Current Project Status This project is currently under active development.

✅ Core Engine: Gravity, collisions, and shooting mechanics.

✅ Character - The Priest: Fully animated (Idle, Run, Jump, Shoot).

⏳ Character - Angel Priest: mechanics and animation pending (Powerup, Idle, Run, Jump, Shoot).

⏳ Character - Cis Male: Design, mechanics and powerup pending.

⏳ Character - POC: Design, mechanics and "Victim Card" logic and animations pending.

⏳ Levels: Tutorial level completed. Dynamic "Social Landscape" levels coming soon.

🛠 Installation & Setup Clone the repo: git clone https://github.com/YourUsername/WrongOnEveryLevel.git

Install Pygame: pip install pygame

Run the game: python main.py

⚖️ Disclaimer This game is a work of satire and dark humor. It does not reflect the actual opinions of the developers.
